Integrated landslide monitoring and emergency-response platform combining **IoT telemetry, ML-based hazard assessment, GIS visualization, citizen reporting, and emergency dispatch**.

- 🧠 AI-assisted field-media verification using computer vision
- 🗺️ Real-time GIS-based hazard and telemetry visualization
- 📱 Stateful WhatsApp-based citizen incident reporting
- 🌐 Multilingual emergency communication for North-East India
- 👥 Human-in-the-loop incident verification and moderation
- 🚨 CAP-compliant emergency alert generation
- 📊 PostgreSQL/PostGIS-backed geospatial data infrastructure
- ⚡ Redis-backed real-time services and caching

**Tech Stack:** `Python` `FastAPI` `React` `TypeScript` `Vite` `PostgreSQL` `PostGIS` `Redis` `Docker` `MobileNetV3` `Twilio`

### ⚛️ Quantum Protocol & Algorithm Visual Simulator

Interactive browser-based platform for exploring **quantum computing algorithms, circuits, and communication protocols** through visual simulation.

Implemented simulations and visualizations for:

`Bell States` · `Quantum Teleportation` · `BB84` · `Quantum Error Correction`  
`Deutsch` · `Deutsch-Jozsa` · `Grover` · `Bernstein-Vazirani`  
`QFT` · `Phase Estimation` · `Shor's Algorithm`

Features include:

- ⚛️ Interactive quantum circuit visualization
- 🌐 Bloch-sphere visualization
- 📈 State-vector and probability visualization
- 🔄 Quantum state evolution
- 📊 Phasor and measurement visualization

**Tech Stack:** `JavaScript` `HTML` `CSS` `Canvas API` `Three.js`
